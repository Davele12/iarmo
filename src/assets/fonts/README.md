# Fuentes locales

Inter y Manrope variables, subconjunto de ASCII, español, diacríticos y signos de interfaz, pesos 400–700. Un WOFF2 por familia: 39.664 y 21.056 bytes.
Descargadas de Google Fonts el 2026-09-18. Licencias SIL OFL adjuntas.
Se sirven con next/font/local: no hay solicitudes a Google en el navegador ni durante el build.

- Extracción reproducible: scripts/fetch-fonts.ps1 consulta https://fonts.googleapis.com/css2 con el subconjunto explícito y descarga los dos WOFF2 de fonts.gstatic.com.
- Documentación: https://nextjs.org/docs/app/getting-started/fonts
