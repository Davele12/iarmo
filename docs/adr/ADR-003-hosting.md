# ADR-003 — Hosting
Estado: aceptado, cuenta pendiente de verificar.
Hostinger Node Web Apps compatible con Next y Node 24. Build/start estándar, sin APIs Vercel. GitHub con rama protegida de producción; no desplegar cada push de una rama sin controles. Export estático descartado por API de formulario. Revalidar plan, proxy y variables en staging.
