# ADR-006 — Agente futuro
Estado: aceptado.
Sólo interfaces intercambiables y documentación en V1. No endpoint que aparente responder ni widget vacío. Futuro servidor controla credenciales, límites, recuperación autorizada y revisión humana. Antes de activar: privacidad, evaluaciones, prompt injection, costes, retención y transferencia a contacto humano.
